# Zadania egzaminowe w aplikacji

**Wszystkie zadania maturalne i E8 są w naszej bazie Supabase** - uczniowie widzą je na `/baza-zadan`, bez wychodzenia na zewnętrzne strony.

## Skąd brać treści

[matematykaszkolna.pl](https://matematykaszkolna.pl/strona/3548.html) może służyć jako **źródło inspiracji** przy pisaniu zadań. Treść przepisujesz (własnymi słowami / opracowanie) w panelu:

**`/admin`** → wybierz miesiąc i rok (np. Arkusz - maj 2024) → wpisz treść i rozwiązanie → Zapisz.

Nie linkujemy uczniów na zewnątrz - to ma być w pełni Szybka Matematyka.
